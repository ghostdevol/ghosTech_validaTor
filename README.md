# ghosTech_validaTor

Multi-chain wallet generator and validator (TypeScript).

Generates and validates wallet keys/addresses across chains, with QR code support. Built on standard primitives (`secp256k1`, `bech32`, `bs58`, ethers project libs).

## Build & run

```sh
npm install
npm run build   # tsc -> dist/
npm start       # builds and serves locally
```
